# 万象十四键交互组件

这个目录是将来完整“万象十四键”主题包使用的可复用交互组件。它不包含万象 schema、词库、Lua、主题图片或 `wanxiang-lts-zh-hans.gram`，因此不能单独作为输入方案使用。

它提供两张临时键盘：

- `wanxiang_14select`：由同文候选栏的 `选字` 按钮进入；发送万象 Pro 实际支持的声调和 `h/s/p/n/z` 五笔形条件。
- `wanxiang_14command`：由可见的 `/` 命令入口进入；提供不折叠的完整 26 键，供万象处理 `/rc`、`/flypy`、`/pinyin`、`/sym...` 等代码。

前提是使用包含本仓库原生会话实现的同文版本。主题组件只定义键盘外观和动作名称；自动进入、取消恢复与提交后回原十四键由同文实现。

完整主题包会把此目录的两个 YAML 合并进自己的 `behavior.yaml` 与 `keyboard.yaml`，并在新的候选栏 / 工具面板设计中提供 `/` 的单击入口。这样五款皮肤共享交互，不需要各自复制 26 键和筛选规则。
