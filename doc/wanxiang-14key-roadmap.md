# 同文·万象十四键：模块路线图

## M0：项目与上游

- 建立 Fork、上游同步策略和许可证/署名文件。
- 记录设计决策、验收标准与变更日志。

## M1：输入方案适配

- 接入万象 Base 的全拼与小鹤双拼。
- 将方案、布局、主题拆成独立状态。
- 保留简拼、补全、词库、Lua 与备份能力。

## M2：十四键交互重构

- 审计经典 `5 / 5 / 4` 布局的每个键、手势和编码冲突。
- 实现十四键与全键共享的功能区。
- 实现 `/` 命令原码层并建立自动返回规则。

## M3：数字工作台

- 重做数字、运算符、成对符号和编辑动作。
- 将日期时间、金额、计算器接入可选择的 Rime 候选结果。

## M4：模型管理

- 实现外置 `.gram` 模型导入、校验、版本提示与部署流程。

## M5：视觉系统

- 独立设计主题、字体、按键状态、候选栏与深浅色模式。
- 不改变已通过输入测试的键位语义。

## M6：测试与发布

- 用真实手机覆盖全拼、双拼、全键、十四键、命令层与数字工作台。
- 产出测试 APK、迁移说明和正式发布包。
