# 同文·万象十四键：设计决策

本文记录已经确认的产品与技术决策。未确认的内容不作为实现假设。

## 产品边界

- 项目只覆盖全键与十四键；九键不在首期范围内。
- 输入方案、键盘布局、视觉主题是三个独立状态，互不强绑。
- 首次启动先选输入方案（全拼 / 小鹤双拼），再选布局（全键 / 十四键）；之后分别记忆。
- 主题单独设计，不参与当前键位与输入逻辑决策。

## 万象方案与模型

- 手机首期采用万象 Base，以支持全拼和小鹤双拼。
- Pro 作为后续兼容模块，不进入首期交互验证。
- `wanxiang-lts-zh-hans.gram` 是外置、必装的运行时模型；APK 不包含该模型。
- 首次启动在方案与布局选择后进入模型安装页；未安装时可浏览设置和主题，但不能启用万象输入。
- 模型管理支持本机导入、官方下载、完整性校验、版本提示和部署。
- 模型更新只提示、不自动下载；用户主动确认且满足网络条件后才下载。新模型校验与部署成功前保留旧模型，以便失败回退。
- 简拼与补全默认保留；禁止再以关闭功能替代输入冲突修复。

## 十四键

- 采用经典 `5 / 5 / 4` 三行骨架。
- 经典双字母配对是默认基线；仅在编码频率、同键冲突和实测都证明有问题时，才做小范围调整。
- 普通十四键是折叠编码层，不承担原始 26 字母输入。
- `/` 进入独立的命令原码层，支持完整输入 `/rc`、`/flypy`、`/sym...` 等命令；退出或上屏后回到十四键。
- 高频能力必须单击可达；长按只承载低频快捷动作，滑动不能是完成关键能力的唯一入口。

## 共用功能区

- 全键与十四键共用同一套候选区、功能区、数字工作台和状态表达，只替换字母区。
- 全键字母区回归干净的 QWERTY 主层；置顶、候选移动、重置等高级 Rime 能力不再作为字母键角标。
- 移除键盘主层的整排工具栏；候选栏保留 `⋯` 作为工具面板入口。
- 空格键不显示方案名称；方案与布局改由候选栏旁的短状态标记表达。
- 点按状态标记打开输入面板，分别选择输入方案、键盘布局与数字行状态；不得使用循环切换。
- 保留一个 `中 / EN` 状态键；系统输入法切换进入长按或工具面板。
- 回车使用当前输入框的系统动作，不显示静态 `Enter` 文案。
- 长按候选词显示候选专属菜单：置顶、左移、右移、清除排序、删除学习记录；删除学习记录需要二次确认。
- 侧边工具面板按“输入、写作状态、管理”分组；表情、翻译、预测、中英标点、半全角保留原有状态与功能，但不与输入方案并列。

## 数字工作台

- 数字行是独立布局选项，默认开启；关闭时以数字工作台承担数字输入。
- 数字行开启时，原 `123` 键改为 `#+=` 符号层；长按切换数字行显示状态。
- 数字工作台提供直接输入的数字、运算符、括号和百分号。
- 日期时间、金额和计算器通过 Rime 候选区提供结果，用户选择后上屏；不得以隐藏长按发送孤立触发字母的方式实现。
- 数字工作台只保留返回布局、退格和动态输入动作；不重复堆放 Delete、返回、退格、Enter 等编辑键。

## 配置状态与部署

- 不把“更新配置”视为完整部署：前者只负责快速重载，后者负责完整编译与检查。
- 管理页提供配置状态：已应用、需要应用、部署失败，以及上次部署时间和版本。
- 提供两个明确操作：`应用配置`（快速重载）与 `重新部署`（完整维护）。
- 导入模型、词库、Lua 或方案后自动尝试完整部署；失败时必须保留手动重试与可读错误说明。

## 保留能力

- 字体自定义、词库导入、Lua 脚本、设置备份与恢复属于基础能力，定制版不得移除。
